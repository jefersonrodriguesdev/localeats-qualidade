# LocalEats - Análise de Qualidade de Software

Repositório destinado à entrega das atividades 1, 2 e 3, de Qualidade de Software.

## 🎯 Objetivo Geral
Aplicar os fundamentos, planeamento, papéis e técnicas de qualidade de software na análise e validação da aplicação [LocalEats](https://local-eats-unisenac.vercel.app/).

## 📂 Estrutura do Repositório

*   **`atividades/atividade-01/`**: Contém a análise de fundamentos (necessidades explícitas e implícitas), requisitos de qualidade e exploração de funcionalidades.
    *   `atividade-01-fundamentos-qualidade.md`
    *   `evidencias/jeferson-criar-conta.png`

*   **`atividades/atividade-02/`**: Contém a definição de papéis, responsabilidades, competências e a estruturação da Matriz RACI para a equipa de desenvolvimento.
    *   `atividade-02-papeis-responsabilidades.md`

*   **`atividades/atividade-03/`**: Contém o planeamento estratégico, análise de riscos, aplicação da técnica de Tabela de Decisão e especificação dos Casos de Teste com rastreabilidade.
    *   `atividade-03-estrategia-projeto-testes.md`

## 🛠️ Contexto Técnico
*   **Metodologia:** Problem-Based Learning (PBL)
*   **Base Tecnológica:** Fundamentos ISO/IEC 25000, técnicas Caixa-Preta (Tabela de Decisão), Matriz RACI e Casos de Teste estruturados.

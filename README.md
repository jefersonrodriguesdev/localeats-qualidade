# LocalEats - Análise de Qualidade de Software

Repositório destinado à entrega da Atividade 1 de Qualidade de Software.

## 🎯 Objetivo
Aplicar os fundamentos de qualidade de software na análise da aplicação [LocalEats](https://local-eats-unisenac.vercel.app/), relacionando necessidades explícitas e implícitas às características de qualidade do produto.

## 📂 Estrutura do Repositório
- `atividades/atividade-01/atividade-01-fundamentos-qualidade.md`: Documento principal com a identificação, necessidades, análise de requisitos e características de qualidade.
- `atividades/atividade-01/evidencias/`: Diretório contendo as capturas de tela (evidências) das explorações realizadas na aplicação.

## 🛠️ Contexto Técnico
- **Metodologia:** Problem-Based Learning (PBL)
- **Base Tecnológica:** Fundamentos de qualidade de software, atributos, critérios e norma ISO/IEC 25000.
